# DrivMatch News — Canonical Market Data Freshness & Close Policy

Status: ACTIVE — 2026-10-13. Applies to the top utility strip, sidebar, mobile, every locale and every published build.

## Principles
1. NEVER show outdated, unverified or made-up rates as current. Refreshing the web page, redeploying HTML or checking a feed does not advance an unchanged price's observation date.
2. Each instrument has independent publication cadence, market-open status, session close, data provenance and redistribution rights. Render observed_at (actual source observation), source, and accurate status. Never confuse observed_at with build/generated_at.
3. USD/BRL commercial spot: use an explicit provider-authorized spot contract (HTTPS, symbol=USD/BRL, instrument=spot, price_type=commercial, source, source_url, authenticated if needed). During an open session, reject any observation older than 5 min. When the provider explicitly reports closed, show its verified close_date/close_value until the next verified price, up to a bounded five-day nontrading window. Never fabricate a close using arbitrary prior ticks. PTAX from the Banco Central is a distinct daily official reference, not interchangeable with real-time commercial spot, and must be labeled PTAX when used as fallback. First try the BCB Olinda OData period API to get the most recent dated sell bulletin (intraday/partial until confirmed final), then SGS 1, then the old commercial close. Never imply intraday PTAX is a commercial FX trade.
4. US on-highway diesel: GASDESW / EIA published weekly, mirrored by FRED. Weekly U.S. EIA retail diesel reference, generally released on Tuesday around 10 AM U.S. Eastern for Monday's surveyed prices (Wednesday after Monday holidays), NOT intraday exchange trading. The next confirmed release after October 5, 2026 is Wednesday October 14, 2026. Hold latest genuine published weekly observation until the next release; alert when delayed. Reject observations older than 12 days from the source-observation date. Never label weekly diesel price as LIVE.
5. Brent oil: default DCOILBRENTEU / EIA daily Brent Europe spot reference, mirrored by FRED: daily observation, sometimes lagging, NOT real-time or Brent futures. Display official daily references up to 5 days old as current-to-source (not live). If the verified latest EIA record is 6–21 days old, retain it ONLY with explicit HISTORICAL / NOT CURRENT warning, suppress change arrow, and link to ICE Brent Futures as a distinct (not equivalent) traded instrument. After 21 days without new official data, hide the value. OPTIONAL licensed physical Brent spot feed requires BRENT_SPOT_URL, BRENT_REDISTRIBUTION_AUTHORIZED=true, optional BRENT_SPOT_TOKEN (GitHub Actions secret), and optionally BRENT_PUBLIC_URL for a licensed CORS-accessible feed polled every 15 seconds in-browser (without exposing any secret). Schema: instrument=brent_spot, unit=USD/bbl, session_status=open|closed; open quotes max 5 minutes, closed quotes contain verifiable close_date and close_value, 5-day cap. Never substitute futures/CFD silently.
6. Source outages: use previously verified quote of the SAME instrument only while still inside its bounded source window; for Brent, only a confirmed historical reference may be retained up to 21 days with a warning. Otherwise show — / temporarily unavailable with alert. Do not extend freshness by reusing cached generated_at.
7. Protected published data includes provider identity, HTTPS source link, observation date/time, cadence/status, close evidence where available, and percentage change only when valid. No fabricated numbers or percentages.

## Refresh and operational QA
- GitHub Actions publication workflow runs on its existing TARGET ten-minute schedule, subject to GitHub delays. Authorized live currency endpoint is polled on page every 15 seconds; static market JSON every 5 minutes. Neither is truly live when provider is unavailable.
- After every build verify schemas, source age, observations and status. Missing quotes should trigger actionable warnings and never restore a frozen number.
- Exchange holidays and publication times matter; never assume 24/7 exchange market or that diesel surveys are traded securities.
- Commercial USD/BRL or Brent spot can only be displayed as live when the matching provider and redistribution authorization are configured.
- No changes to advertising art, ads placement, editorial chronology, languages or layout are authorized by this rule.

## Market Source Reliability & Audit — ACTIVATED 2026-10-13

Owner approval: "Aprovado / Ativar / Salvar" — 2026-10-13. This policy supersedes any workflow that leaves stale quotes unaudited. The user is NOT the human auditor for missing or frozen quotes.

- The published GitHub Actions workflow is scheduled at the ten-minute target (GitHub Actions may delay scheduled executions). Every update attempts approved sources and records instrument, observation time, source and release status. A new build is not a new market quote.
- **Priority — USD/BRL:** contractually authorized commercial provider, optional separately authorized AwesomeAPI spot-ask adapter, official BCB Olinda PTAX (explicitly marked PTAX/intraday or close), BCB SGS daily PTAX, bounded last verified commercial close. Never scrape UOL: UOL is a cross-check link, not an API license.
- **Priority — U.S. diesel:** EIA official weekly API (EIA_API_KEY when provided), FRED's identical EIA GASDESW series as backup; release calendar including U.S. holidays. TradingView FRED:GASDESW is a reader cross-check, not a separate faster source. No claim of intraday retail diesel.
- **Priority — Brent:** EIA official daily physical spot reference (EIA_API_KEY), FRED EIA observation backup, optional licensed Brent spot provider where contracted; Investing Brent futures and NYMEX ULSD may be linked only as *distinct financial instruments*. If the EIA source has stopped, a historical observation must carry an explicit NOT CURRENT label.
- **Publication source gates:** AWESOMEAPI_API_KEY and EIA_API_KEY are secret environment variables and never in client files. AWESOMEAPI_REDISTRIBUTION_AUTHORIZED, BRENT_REDISTRIBUTION_AUTHORIZED and USDBRL_REDISTRIBUTION_AUTHORIZED must be explicitly set based on valid use rights. User approval of this *policy* is not proof of any provider's data license.
- **Self-audit:** scripts/audit_market.py records the actual provider state and detects source-publication lag, including EIA weekly release-day adjustments. GitHub Actions opens/updates one persistent [Market Watch] issue when feeds are late, quotes invalid or an upstream build fails before the audit; it closes only after recovery. Never silently close an active source failure.
- **Protected scope:** No advertising artwork, placement, newspaper typography, editorial order, or unrelated products may be changed by market-feed maintenance.
- **Acceptance gate:** Successful commit alone is not proof that drivmatch.com/news is updated. Confirm the scheduled workflow succeeds, public market JSON carries new observation dates, and the same values plus their status are displayed in the rendered desktop/mobile header and market panel.

## Canonical compact market presentation — approved 2026-10-13

- The public quote strip and market sidebar MUST show only **instrument name + valid current/reference price + percentage change**. Never print long paragraphs, audit explanations, observation dates or third-party comparison links beneath these three values.
- Source, true observation time, instrument type, freshness classification and errors remain in the data contract, behind-the-scenes audit, a readable HTML title/accessible text and GitHub Market Watch. Do not delete the underlying provenance to simplify visual layout.
- In the same slot, changing market data updates the values and variations in place. When unchanged at source, preserve the legitimate last verified close or last published weekly diesel reference. Do not simulate tick-by-tick pricing for weekly diesel.
- **USD/BRL:** when only BCB PTAX is available, call it "Dólar PTAX", never label it "Dólar comercial". A commercial spot label requires actual licensed commercial quote data.
- **Brent:** if the most recent EIA physical Brent data is classified historical, do NOT show that historic numeric value as a current market price. Render an em dash until a genuinely current source observation or separately licensed Brent feed is available. Keep the older value in diagnostics, not in the customer quote.
- Keep all three slots visible, with an em dash on unavailable values. No fabricated numbers, no legal/technical paragraphs in public UI.
- Preserve mobile compact scale, no new lines beneath the price. PT/EN/ES must follow the same rules. Tests must enforce no visible market-provenance footers and no historical Brent marketed as live.
- This is only a presentation adjustment; changing the HTML does not activate unlicensed real-time providers. Publication success requires the public-domain parity and source freshness checks, not a GitHub commit alone.
